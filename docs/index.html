01

Быстрый стартQuick start

  1. 01

    Скачайте и установите Aeroway-Setup.exe. Download and install Aeroway-Setup.exe.

  2. 02

    При первом запуске дождитесь загрузки компонентов Flowseal. On first launch wait for Flowseal components to download.

  3. 03

    Добавьте папку программы в исключения антивируса и разрешите Aeroway.exe и winws.exe в брандмауэре — раздел «Антивирус и брандмауэр». Add the app folder to antivirus exclusions and allow Aeroway.exe and winws.exe through the firewall — see Antivirus and firewall.

  4. 04

    На вкладке Главная выберите стратегию и нажмите ЗАПУСТИТЬ. On Home pick a strategy and press START.

02

Антивирус и брандмауэрAntivirus and firewall

Исключения в антивирус и правила брандмауэра добавляются вручную. Без них Windows Defender может удалить WinDivert и winws.exe, а брандмауэр — заблокировать запуск. Antivirus exclusions and firewall rules are added manually. Without them, Windows Defender may remove WinDivert and winws.exe, and the firewall may block startup.

После установки программа лежит в %LOCALAPPDATA%\Aeroway — обычно C:\Users\<имя>\AppData\Local\Aeroway. Внутри неё находится zapret\bin\winws.exe. After installation the app is in %LOCALAPPDATA%\Aeroway — usually C:\Users\<name>\AppData\Local\Aeroway. zapret\bin\winws.exe is inside that folder.

Windows Defender

  1. Откройте Безопасность Windows. Open Windows Security.
  2. Защита от вирусов и угроз → Управление настройками. Virus & threat protection → Manage settings.
  3. Исключения → Добавление или удаление исключений → Добавить исключение → Папка. Exclusions → Add or remove exclusions → Add an exclusion → Folder.
  4. Укажите %LOCALAPPDATA%\Aeroway. Select %LOCALAPPDATA%\Aeroway.

Если установлен другой антивирус, добавьте ту же папку в его исключения. Срабатывание с именем WinDivert или Not-a-virus:RiskTool.Multi.WinDivert относится к драйверу zapret: файл нужно восстановить из карантина и оставить папку в исключениях. With another antivirus, add the same folder to its exclusions. A detection named WinDivert or Not-a-virus:RiskTool.Multi.WinDivert is the zapret driver: restore the file from quarantine and keep the folder excluded.

Брандмауэр WindowsWindows Firewall

  1. Безопасность Windows → Брандмауэр и безопасность сети → Разрешить работу с приложением через брандмауэр. Windows Security → Firewall & network protection → Allow an app through firewall.
  2. Нажмите Изменить параметры (нужны права администратора). Click Change settings (administrator rights required).
  3. Разрешить другое приложение → Обзор и добавьте оба файла: Allow another app → Browse and add both files:
    • %LOCALAPPDATA%\Aeroway\Aeroway.exe
    • %LOCALAPPDATA%\Aeroway\zapret\bin\winws.exe
  4. Для каждого файла отметьте частную и публичную сеть. For each file, allow private and public networks.

06

Если не работаетIf it does not start

  1. 01

    Антивирус забрал WinDivert или winws.exe. Восстановите файл из карантина и исключите папку %LOCALAPPDATA%\Aeroway. Срабатывание Not-a-virus:RiskTool.Multi.WinDivert относится к драйверу zapret. Antivirus removed WinDivert or winws.exe. Restore the file from quarantine and exclude %LOCALAPPDATA%\Aeroway. A detection named Not-a-virus:RiskTool.Multi.WinDivert is the zapret driver.

  2. 02

    Брандмауэр молча блокирует запуск. Разрешите Aeroway.exe и zapret\bin\winws.exe для частной и публичной сети. The firewall blocks startup quietly. Allow Aeroway.exe and zapret\bin\winws.exe on private and public networks.

  3. 03

    Сайты всё ещё не открываются. Смените стратегию или обновите Flowseal в разделе «Сервис». Sites still do not open. Change the strategy or update Flowseal in Service.

  4. 04

    Окно не открывается. Поставьте последнюю версию со страницы релизов. The window does not open. Install the latest build from the releases page.

07

Файлы и удалениеFiles and removal

После установки программа лежит в %LOCALAPPDATA%\Aeroway. Обычно это C:\Users\<имя>\AppData\Local\Aeroway. Движок — в zapret\bin\winws.exe. After installation the app is in %LOCALAPPDATA%\Aeroway, usually C:\Users\<name>\AppData\Local\Aeroway. The engine is zapret\bin\winws.exe.

Удаление — через «Приложения и возможности», имя Aeroway. Ярлык и иконка тоже от Aeroway. Remove it from Apps & features under the name Aeroway. The shortcut and icon use that name too.

Если при удалении папки Windows пишет, что занят WinDivert64.sys, драйвер ещё загружен. Остановите обход, затем в PowerShell от администратора: If Windows says WinDivert64.sys is in use, the driver is still loaded. Stop the bypass, then in an administrator PowerShell window: 

sc.exe stop WinDivert
sc.exe delete WinDivert

В PowerShell нужна именно команда sc.exe. После этого файл отпускает папку. In PowerShell the command must be sc.exe. After that the file no longer locks the folder.
