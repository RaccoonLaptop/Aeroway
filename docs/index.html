Быстрый старт

  1. Скачайте и установите Aeroway-Setup.exe.
  2. При первом запуске дождитесь загрузки компонентов Flowseal.
  3. Добавьте папку программы в исключения антивируса и разрешите ZapretUI.exe и winws.exe в брандмауэре — см. раздел ниже.
  4. На вкладке Главная выберите стратегию и нажмите ЗАПУСТИТЬ.

Антивирус и брандмауэр

Исключения в антивирус и правила брандмауэра добавляются вручную. Без них Windows Defender может удалить WinDivert и winws.exe, а брандмауэр — заблокировать запуск.

После установки программа лежит в %LOCALAPPDATA%\ZapretUI — обычно C:\Users\<имя>\AppData\Local\ZapretUI. Внутри неё находится zapret\bin\winws.exe.

Windows Defender

  1. Откройте Безопасность Windows.
  2. Защита от вирусов и угроз → Управление настройками.
  3. Исключения → Добавление или удаление исключений → Добавить исключение → Папка.
  4. Укажите %LOCALAPPDATA%\ZapretUI.

Если установлен другой антивирус, добавьте ту же папку в его исключения. Срабатывание с именем WinDivert или Not-a-virus:RiskTool.Multi.WinDivert относится к драйверу zapret: файл нужно восстановить из карантина и оставить папку в исключениях.

Брандмауэр Windows

  1. Безопасность Windows → Брандмауэр и безопасность сети → Разрешить работу с приложением через брандмауэр.
  2. Нажмите Изменить параметры (нужны права администратора).
  3. Разрешить другое приложение → Обзор и добавьте оба файла:
    • %LOCALAPPDATA%\ZapretUI\ZapretUI.exe
    • %LOCALAPPDATA%\ZapretUI\zapret\bin\winws.exe
  4. Для каждого файла отметьте частную и публичную сеть.

Решение проблем

  • Антивирус удалил WinDivert или winws — восстановите файл из карантина и добавьте папку %LOCALAPPDATA%\ZapretUI в исключения.
  • winws не запустился — запуск от администратора, разрешение в брандмауэре, другая стратегия.
  • Не открывается окно — установите последнюю версию с GitHub.
  • Сайты не работают — обновите Flowseal в «Сервис», смените стратегию.

Quick start

  1. Download and install Aeroway-Setup.exe.
  2. On first launch wait for Flowseal components to download.
  3. Add the app folder to antivirus exclusions and allow ZapretUI.exe and winws.exe through the firewall — see the section below.
  4. On Home pick a strategy and press START.

Antivirus and firewall

Antivirus exclusions and firewall rules are added manually. Without them, Windows Defender may remove WinDivert and winws.exe, and the firewall may block startup.

After installation the app is in %LOCALAPPDATA%\ZapretUI — usually C:\Users\<name>\AppData\Local\ZapretUI. zapret\bin\winws.exe is inside that folder.

Windows Defender

  1. Open Windows Security.
  2. Virus & threat protection → Manage settings.
  3. Exclusions → Add or remove exclusions → Add an exclusion → Folder.
  4. Select %LOCALAPPDATA%\ZapretUI.

With another antivirus, add the same folder to its exclusions. A detection named WinDivert or Not-a-virus:RiskTool.Multi.WinDivert is the zapret driver: restore the file from quarantine and keep the folder excluded.

Windows Firewall

  1. Windows Security → Firewall & network protection → Allow an app through firewall.
  2. Click Change settings (administrator rights required).
  3. Allow another app → Browse and add both files:
    • %LOCALAPPDATA%\ZapretUI\ZapretUI.exe
    • %LOCALAPPDATA%\ZapretUI\zapret\bin\winws.exe
  4. For each file, allow private and public networks.

Fresh install defaults

  • Game Filter: TCP + UDP (ports can be customized, e.g. exclude RTMP: 1024-1934,1936-65535)
  • IPSet: loaded
  • Home background: Wavy

Troubleshooting

  • Antivirus removed WinDivert or winws — restore the file from quarantine and exclude %LOCALAPPDATA%\ZapretUI.
  • winws did not start — run as administrator, allow it in the firewall, try another strategy.
  • Window won’t open — install the latest release from GitHub.
  • Sites still blocked — update Flowseal in Service, change strategy.
